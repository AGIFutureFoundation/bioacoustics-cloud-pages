The Sound Map

See how species sound — side by side

Add clips from different animals. WAVE builds an acoustic fingerprint for each one and arranges them so that distance means similarity: clips that share spectral structure sit close together. Hover any point to see its spectrogram.

Honest by design. This maps acoustic structure, not fabricated meaning. Feature-based similarity groups sounds by timbre and rhythm — clean species-level separation and behavioural meaning arrive when the foundation model (Perch / NatureLM) is switched on. The interface stays identical; only the fingerprint gets deeper.
